# openstudio-server — GPU pod requirements (RunPod pytorch image: torch 2.8.0+cu128, py3.12).
#
# HARD RULE: torch is provided by the image and NOTHING here may reinstall it.
#   - None of these packages hard-pin torch (accelerate/diffusers require it
#     loosely, so pip's resolver keeps the installed 2.8.0+cu128).
#   - streamdiffusion itself is installed by run.sh with --no-deps (its
#     setup.py pins diffusers==0.24.0 etc.; we supply those pins here so pip
#     can never "resolve" our torch away).
#   - run.sh re-verifies `torch.__version__` after install and fails loud.
#   - xformers is deliberately ABSENT: its wheels pin exact torch builds and
#     will shadow system torch. torch 2.8 SDPA (AttnProcessor2_0) is plenty on
#     a 4090 at 512x512 batch-2. If you must try it: install with --no-deps
#     and re-verify torch, then run server.py --xformers.
